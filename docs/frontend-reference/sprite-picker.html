This runs entirely client-side — the image file never leaves your browser. Once you have sx/sy/sw/sh for each frame you need (player, professor, the enemy, your rotation's crops), paste them into the matching entry of SPRITE_ASSETS near the top of the game's script, and set src to the image file's path (or a data: URL if you're keeping everything in one file).
